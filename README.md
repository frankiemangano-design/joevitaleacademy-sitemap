# joevitaleacademy-sitemap

Public GitHub Pages host for the branded XML sitemap of
https://joevitaleacademy.com/blog.

- Serves `https://sitemap.joevitaleacademy.com/sitemap.xml`
- The file is regenerated by `blog/pipeline/generate_sitemap.py` in the main
  operator repo and pushed here by a scheduled GitHub Action.
- No credentials, no customer data, no private documentation ever land here.
